## どんなゲームか

魔王城に、勇者ご一行がやってきます。決戦しに来たのではありません。**精算に来たのです。**

世界を救う旅にかかった宿代、消耗品、装備、そして「ドラゴン討伐費」。
その領収書の束を審査するのが、あなた——**魔王**の仕事です。

勇者の申請は、雑です。日付が合わない。数が合わない。買ったはずのものが減っていない。
おかしいと思ったら、証拠を突きつけて言ってください。

**「差し戻し！」**

物語を読むだけのゲームではなく、**あなた自身が伝票を読んで、承認するか差し戻すかを決めるゲーム**です。

## 遊びかた

クリック（タップ）で会話が進みます。

- **決裁**：伝票の品目と金額を見て、**承認**か**差し戻し**かを選びます。差し戻すなら、根拠になる証言・記録を1つ選んで突きつけます
- **呼び出し**：審査の途中で、勇者の仲間を証人として呼べる場面があります。何回呼んでも損はしません
- **幕間**：魔王を上下左右に歩かせて、城の中で仲間に話しかけられます
- 判断を間違えると**魔王の胃が痛みます**。痛めすぎると**ゲームオーバー（全4幕）**。……ちゃんと戻ってこられるので、安心して間違えてください
